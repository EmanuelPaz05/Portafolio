PROYECTO 02 / AUTOMATIZACIÓN · 2026

Reportes comerciales, sin trabajo manual repetitivo.

Demostración académica independiente de un proceso que implementé en Net-Gestión: transformar ventas en un resumen y preparar automáticamente un reporte por correo.

Ver código y documentaciónProyecto principal: Net-Gestión

El problema

Revisar ventas, calcular totales y preparar correos a mano consume tiempo y puede generar errores. La automatización permite repetir ese proceso con información estructurada.

Entrada

Registros ficticios de ventas en JSON y una fecha seleccionada.

Proceso

Filtrado, validación, suma de importes y armado de plantillas.

Salida

Reporte JSON y HTML, con envío opcional por Resend en entorno de prueba.

Flujo automatizado

  1. Leer las ventas del día y validar las cantidades.
  2. Calcular facturación total, operaciones y unidades.
  3. Generar archivos de reporte en JSON y HTML.
  4. Mostrar una vista previa local o, con autorización y credenciales de prueba, enviar por Resend.

Cómo ejecutarlo

git clone https://github.com/EmanuelPaz05/NetGestion-Automatizacion-Reportes.git
cd NetGestion-Automatizacion-Reportes
npm start -- --date=2026-11-11
npm test

La demo se ejecuta con Node.js 18 o superior y datos ficticios; el envío real está desactivado por defecto. No utiliza datos ni código comercial de Net-Gestión.

Arquitectura y tecnologías

Node.js

Procesamiento de reportes y ejecución por línea de comandos.

Resend

Integración opcional para pruebas de envío transaccional.

GitHub Actions

Flujo de pruebas y ejecución del ejemplo documentado.
