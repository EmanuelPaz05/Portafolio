## Proyectos para el coloquio integrador 2026

| Proyecto | Sitio / repositorio |
| --- | --- |
| **Net-Gestión — producto comercial** | [netgestion.ar](https://netgestion.ar/) |
| **Net-Gestión — presentación técnica** | [NetGestion-Presentacion](https://github.com/EmanuelPaz05/NetGestion-Presentacion) |

La página de automatización incluye el problema, la solución, el proceso, tecnologías y enlaces al código ejecutable. Se trata de una **demo independiente con datos ficticios**, no del código comercial de Net-Gestión.

## Publicación en Vercel

**Actualización 11/11/2026:** se identificó y usó el proyecto original del portfolio (archivo local proporcionado por Emanuel). Se publicó en producción la página de automatización y se agregó la vinculación de los dos proyectos. **El dominio actual está actualizado en Vercel**. Este repositorio contiene la nueva página y el script de integración, pero todavía no es una copia completa de todos los archivos fuente del despliegue.

Para actualizar la web sin perder su diseño actual:

1. Abrir la carpeta local que se usó para publicar `emanuel-paz-portfolio.vercel.app`.
2. Copiar allí `proyectos/automatizacion-reportes.html` desde este repositorio.
3. En la sección «Proyectos» del `index.html` local, agregar una tarjeta de «Automatización de reportes» enlazada a `proyectos/automatizacion-reportes.html`, y agregar un enlace al repositorio [NetGestion-Presentacion](https://github.com/EmanuelPaz05/NetGestion-Presentacion) en la tarjeta de Net-Gestión.
4. Probar ambos enlaces y publicar desde la carpeta correcta con `vercel --prod`, usando el mismo proyecto de Vercel.

**No reemplazar el `index.html` moderno de Vercel por un archivo antiguo de este repositorio.**
