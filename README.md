## Publicación en Vercel

**Importante:** el sitio publicado actualmente fue desplegado a Vercel por CLI desde otra copia de archivos. Los archivos de la rama `main` de este repositorio **no coinciden con la versión moderna publicada** y los cambios hechos aquí **no se despliegan automáticamente**.

Para actualizar la web sin perder su diseño actual:

1. Abrir la carpeta local que se usó para publicar `emanuel-paz-portfolio.vercel.app`.
2. Copiar allí `proyectos/automatizacion-reportes.html` desde este repositorio.
3. En la sección «Proyectos» del `index.html` local, agregar una tarjeta de «Automatización de reportes» enlazada a `proyectos/automatizacion-reportes.html`, y agregar un enlace al repositorio [NetGestion-Presentacion](https://github.com/EmanuelPaz05/NetGestion-Presentacion) en la tarjeta de Net-Gestión.
4. Probar ambos enlaces y publicar desde la carpeta correcta con `vercel --prod`, usando el mismo proyecto de Vercel.

**No reemplazar el `index.html` moderno de Vercel por un archivo antiguo de este repositorio.**
